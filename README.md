# Nexus Engine 🟣

**Nexus Engine** é uma game engine 2D/3D baseada no Godot Engine, personalizada por **Brayan Borges**.
Visual roxo, identidade própria, mesma potência de baixo nível.

## Recursos
- Editor completo 2D e 3D com tema roxo Nexus
- GDScript, C#, C++ (GDExtension)
- Export para Windows, Linux, macOS, Android, iOS e Web
- 100% open source (MIT)

## Compilação
```bash
scons platform=linuxbsd target=editor
```
Consulte a documentação oficial de build do Godot para as demais plataformas.
